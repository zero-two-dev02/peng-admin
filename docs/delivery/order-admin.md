# 管理员订单查询与详情交付记录

日期：2026-09-11

## 页面与接口

- 路由：`/order/orders`，导航分组为“交易 → 订单管理”。
- UI 与后端权限：`order:read`；无权限时由现有路由守卫进入 403。
- 列表：`GET /order/admin/orders`，提交订单号、用户 ID、状态、页码和页大小；订单号按精确值查询。
- 详情：`GET /order/admin/orders/{id}`，点击行操作后重新发起请求，不使用列表行冒充详情。

## 页面事实边界

列表和详情仅显示 Order 服务返回的订单自身事实：订单号、用户 ID、商品快照、SKU 规格、数量、金额分、状态、创建/更新时间、过期时间及取消字段。金额使用现有分转元函数；未知状态显示“未知状态（原始值）”；时间不做时区加减。

页面不显示或虚构用户昵称、支付状态、库存状态、物流信息、退款信息，也没有支付成功、退款、发货等未实现操作按钮。
